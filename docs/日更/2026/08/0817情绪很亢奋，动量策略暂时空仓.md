# 情绪很亢奋，动量策略暂时空仓

## 今日复盘

1、今天ETF趋势模型已经没有空头了，所有的ETF都转为了多头或震荡，从发布趋势模型以来还没有出现过这种情况。我查了一下：确立空头只有1只的时间，分别是今年的4月17、4月20、4月23；确实空头只有2只的时间，集中在今年的4月15日到5月14日。从过往数据来看，确立空头少，只能说明市场情绪当前比较亢奋，有可能接近短期高点，但并不能精准判断短期高点。

2、包括ETF资金流向，今天依然是净流出的，但这个数据也不能够判定市场的高低点。比如今年的4~6月份，只有两个交易日资金是净流入的，但是并不妨碍指数新高走出一个先冲高后大跌的A字。

3、今天大涨的驱动力可以拆成四条线：外部流动性松了（美联储加息预期骤降）、科技产业趋势催化了（美国GPU巨头官宣CPO交换机全面量产，还有关于中际旭创、新易盛产品获“额外豁免”的小作文）、政策预期撑住了（国内政策在持续输出暖意，虽然没有大利好，但一直在给不会收紧的预期）、情绪自己滚起来了（周末《牛来》电影爆火）。四条线叠在一起，才有了这根阳线。

4、这种情况下，做判断越来越难了，还是老办法，按策略来。场外的四维轮动晃晃悠悠的一直在往上涨。场内的ETF轮动我还是按照动量策略信号来，今天尾盘又恢复了空仓。
