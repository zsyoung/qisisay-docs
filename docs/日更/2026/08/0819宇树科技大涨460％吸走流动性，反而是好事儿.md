# 宇树科技大涨460％吸走流动性，反而是好事儿

## 今日复盘

今天这根大阴线，很多人又开始找原因了，大部分都把矛头指向了美债收益率飙升，我说几个反常识的点。

**1、反常识一：今天大跌，美债不是最关键的原因**

美债收益率飙到5.33%是事实，但上周就有苗头了，为什么偏偏今天才崩？因为前面涨的东西根基不牢。涨得太假了。科创50从8月低点上来涨了将近20%，但这20%里头，小作文和杠杆的贡献远大于盈利。美债往上戳的时候，这层窗户纸已经很薄了，今天只是正好被戳破。炸药其实在前面那20%的涨幅里就埋好了。

**2、反常识二：银行和煤炭走强，并不是避险**

煤炭涨0.73%、银行涨1.78%，主流解读是资金躲防御。但你想想，真要避险为什么不直接买国债？今天国债收益率也在涨，银行股照样涨。说明资金并不是避险。美债飙升压缩了国内政策空间，反而让市场觉得国内要更快宽松了（降准降息）。银行股高股息、受益于宽信用，提前抢跑了。

**3、反常识三：新股宇树科技吸走大量成交，反而是好事儿**

新股宇树科技大涨460%，都在骂它虹吸流动性。但换个角度，一只新股能吸走几百亿成交，恰恰说明市场不缺钱，缺的是信心。2.53万亿成交，放量1100亿，如果真是恐慌性出逃应该是缩量的，没人接。今天放量，说明有人在大跌中接盘。接盘的钱大概率是从科技高位撤出来、调到低估值的那批。筹码加速换手，往往是短期见底的信号。

**4、反常识四：急跌比阴跌更好**

科创50一天跌近7%，很多人觉得完了。但急跌比阴跌好。阴跌没底，急跌是情绪一次性释放。今天通信、电子跌了快8%，跌停板上全是高位小票，机构重仓的半导体设备龙头跌幅反而有限。从ETF资金流向来看，宽基今天是净流入的，流入最多的是创业板ETF。机构没有恐慌性减仓，减的是散户和杠杆。一旦外围企稳，被错杀的机构票会是第一批反弹的。
