# 存量博弈的循环抽水阶段

## 今日复盘

1、今天市场最刺眼的是风格切换的暴力程度。创业板指涨5.64%，通信板块涨9.41%，而银行跌2.75%，四大行均跌超3%，农业银行跌超4%。市场依然是存量博弈的循环抽水阶段，资金主要在三个池子里倒：科技线、红利防御、小微盘。

2、存量博弈这件事，量能是最直接的证据。7月7日A股成交额一天掉了5100亿缩到2.6万亿，7月24日更跌破2万亿创三个多月新低。今天2.21万亿虽然比昨天2.01万亿放量，但跟前期3万亿以上的水平比，明显是场内资金在倒手，不是增量进场。

3、最近一个月资金就在三个池子里来回倒。科技线7月初被韩国存储芯片地震带崩，中际旭创一度跌超15%，今天又借着美股映射回流；红利防御7月28日银行白酒还逆势护盘，今天就翻脸大跌；小微盘7月3日和8月3日两次出现微盘股指数涨3%以上而大盘蓝筹下跌的背离。三个方向轮完一圈，资金没处去，就临时去超跌板块打野。

4、存量博弈的末期，资金回流超跌的小微盘，阻力最小。因为微盘股市值小，资金回流时弹性大，跌透后反弹力度往往不小。微盘股从5月12日到7月20日连跌49个交易日，跌幅25.9%，我在微盘股指数跌破前低后选择了割肉，目前看确实是割在了底部，过度使用了技术分析，忽略了估值和跌幅。但底部砍仓后最忌讳追着轮动跑，很容易两头挨打。而且经过长期的研究后，我发现微盘股根本没有非常靠谱的择时指标辅助逃顶抄底，它的高波动注定了这个策略不适合长持，它赚的是弹性钱，并不是长持钱。我继续耐心等待下一个大机会。

5、今晚光模块出了海外利空，路透援引知情人士称，美国联邦通讯委员会正在起草禁止进口部分中国数据中心元件的禁令，范围包括新型光模块。禁令还在起草阶段没落地，但明天科技线承压是大概率。如果科技回调，资金往小微盘切的概率更高，但这不是追进去的理由，反而是等回调回补的窗口。

6、既然当前判断是存量博弈持续，而且微盘股的大反弹是因为前期超跌，不是基本面好转，那么它更可能和红利一样再次出现像样的回调。想回补的话，等微盘股指数回踩20日均线不破会更合适。
