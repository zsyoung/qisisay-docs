# A股风险偏好回来了，黄金却迎来一盆冷水

## 今日复盘

1、今天我觉得最重要的，不是指数涨了多少，而是早盘明显承压之后，下午还能自己拉回来。全市场一度超过3000只股票下跌，收盘却超过3100只上涨。这个过程比单纯高开高走更有意义，至少说明抛压出来以后，下面有人接。

2、成交量也没有拖后腿。两市成交2.13万亿元，比上个交易日增加293亿元，不算特别大，但至少不是缩量硬拉。所以我倾向于认为，上周大跌后的情绪还在修复，市场开始有一点企稳的样子。

3、科技今天也明显回来了。AI应用、短剧、液冷、端侧AI、算力芯片都在涨，但科技回暖是真的，重新回到以前那种抱团科技行情，目前还没有证据，大盘拥挤度45.69%也比之前低很多；现在更像内部轮动，谁跌得多、谁有新催化，资金就先去做谁。

4、而且今天强的不只有科技，银行同样很强，中国银行、中信银行继续创历史新高。资金一边做成长，一边还在买高股息，说明风险偏好在恢复，但还没有恢复到敢把钱重新全部压向高弹性方向。

5、所以今天之后，我对市场比上周乐观一些。但4000点就在前面，量能也只是温和恢复，现在说新一轮主升开始了，我觉得证据还不够。先看这轮修复能不能继续，不能因为一天上涨又把预期打满。

6、黄金今天也值得单独说。上周五伦敦金单日跌超3%，今天仍在两周低位附近，主要压力来自美联储加息预期升温，美国10年期国债收益率也升到4.73%左右。而且，美伊冲突升级本来利好避险，但油价上涨又推高通胀担忧，市场又开始交易“利率更高更久”。

反正黄金这个逻辑，经常正说反说都有道理。真要选一个最朴素的解释，就是前面涨得太快了，现在需要消化一下。后面利率、美元、ETF资金和央行购金还会继续拉扯，短期可能还有压力，但目前没有证据说明中期趋势已经反转。
