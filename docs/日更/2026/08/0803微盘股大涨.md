# 微盘股大涨

## 今日复盘

1、今天的市场比指数显示的健康得多。科创50暴跌5%是半导体权重股大跌，跟全市场4005只上涨不矛盾。钱没有离开市场，只是从拥挤的AI/半导体仓位往中小盘、低估值方向挪。这个"指数跌、个股涨"恰好是前阵子"指数涨、个股跌"的镜像，反而更健康。

2、半导体暴跌是输入型的，亚洲去杠杆还没走完。韩国KOSPI上周五暴涨18%后今天跌5%触发冷静机制，三星SK海力士跌8%，日本联合美国干预日元打乱套利交易。国内AI链再次被拖下水。而且按国金的研报，国内AI链筹码出清信号比海外更弱——公募还在高仓位扛着，"固收+"基金AI仓位创三年新高还没开始跑。如果这波亚洲去杠杆继续，国内AI链可能还有下行空间。

3、微盘指数今天涨了3.87%，但这更像是一场技术性修复。从5月中旬算起，它已经连跌了51天、累计回撤29%，调整的时间和空间都逼近了历史极值。历史规律显示，这种级别的调整后，短期内大概率会迎来一波均值回归的反弹。所以今天的上涨，本质上是空头动能衰竭后的自然反抽。

4、科技抱团越拥挤，瓦解后的再平衡就越剧烈。现在微盘股指数5日线上穿20日线，确认了短期反弹趋势，如果愿意接受"概率优势+估值安全边际"的逻辑，而不是"底部确认"的逻辑，那当前的信号组合（扩散模型翻多+估值低分位+历史反弹概率高）已经具备了左侧小仓位布局的条件。
