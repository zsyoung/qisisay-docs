# 三天缩量7700亿

## 今日复盘

1、前天2.97万亿，昨天2.67万亿，今天2.2万亿。三天，成交额缩了7700亿。

前天那根大阳线看着热闹，但量是空头回补和政策资金撑出来的，不是真有新钱进场。回补完，就没人了。今天2.2万亿，已经快摸到2万亿的坎了，再往下缩，连存量腾仓的动力都没了。

2、科创50今天高开低走，收盘跌3.78%。半导体更惨，华虹宏力跌12.58%，中芯国际跌6.75%。下周一长鑫科技在科创板挂牌上市，机构担心流动性吸血提前撤是本能反应。但一个还没上市的IPO就能把整个半导体板块砸趴，本身就说明现在市场信心薄得跟纸一样，承接力几乎没有。长鑫上市当天还要再吸一波资金，抽血效应落地之前，半导体很难指望能稳。

3、有意思的是，4200只股票上涨，微盘股涨了4.16%，电网设备30多股涨停，立新能源6连板，锂矿有色煤炭油气全在动。前两天跌最狠的小票今天反而涨了。仔细想这并不矛盾。成交额缩成这样，没有新钱进来，资金只能从高位科技里抽出来，往低位板块塞。电网、锂矿、有色这些方向估值低、位置低，跌也跌不到哪去，资金觉得安全。但说到底就是里面的人互相搬运，不是什么新行情启动。

4、万得全A今天大部分时间站在5日线上方，7月初调整以来头一次。空头力度确实在减弱，但缩量环境下这个信号要打折看，并不是买盘强了，是卖盘暂时累了。微盘股近20天累计还是跌5个点，对数回归位置还不够便宜，一个4%的反弹改变不了什么。继续耐心等待大机会。

5、这周下来，几乎是每天换一个方向涨，每天换一个方向跌，频繁操作的话，肯定是追哪个套哪个。最好多看少动。震荡里最该做的事不是找机会，是别犯错。
