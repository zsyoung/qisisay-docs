# 风格切换继续，今晚又有大事件！

## 今日复盘

1、今天反弹了，但根在韩国不在自己。韩国KOSPI早盘又崩10%，触发年内第八次熔断，SK海力士二季报利润同比涨557%但没到预期，盘中狂砸19%。午后韩国在年线附近站住反弹，收盘收窄到跌6%，A股跟着翻红。沪指涨0.4%，创业板涨1.55%，科创50跌0.87%是唯一收绿的宽基。

2、反弹力度并不强。中证全指昨天跌2.74%，今天才涨0.77%，不到三分之一。两市2.3万亿看着放量了，但主要是午后跟着韩国弹的时候带起来的，早盘还在跌。

3、风格切换进入第三天。27号科技消费共振上涨，28号科技崩消费扛住，今天科技盘中跳水但尾盘拉回收绿，消费继续涨。2.3万亿放量的方向是传媒、零售、食品饮料，不是CPO和半导体。如果只是恐慌躲一下，今天放量的时候该回去抄科技了，但并没有。资金依然在用脚投票风格切换。这个风格切换是暂时的还是持续的，取决于外力。

4、而外力目前都不乐观，美联储加息预期升温，大资金托底不持续，国内政策转向没音信，韩国止跌回稳也没看到。因此现在还是不能期待调整短期结束，要做好调整几周到几个月的准备。

5、今晚是超级夜。凌晨2点美联储出结果，加息25bp概率从两周前的10%升到36%，然后微软Meta盘后财报。这两个事任何一个超预期，明天又是大波动。万一外围利空，今天的放量阳线明天可能又变成套牢盘。

6、策略上，依然不急于抄底科技，少看少动。如果非要入场，最好挑选有安全垫的可转债或者配债股。
